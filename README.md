# Sistema de Alquiler de Vehículos

## Descripción del Proyecto
Aplicación CLI en Python para gestionar reservas de vehículos. El sistema permite realizar reservas en un rango de fechas, validar la disponibilidad del vehículo seleccionado y gestionar su estado (Disponible, Alquilado, En Mantenimiento).
